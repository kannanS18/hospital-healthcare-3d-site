# 🏥 MediCare+ — 3D Hospital & Advanced Healthcare Platform

A medical web platform built with **React Three Fiber**, **Three.js**, **Framer Motion**, and **Tailwind CSS**.

Featuring a real **3D Cranial Diagnostic Scanner** and **Molecular DNA Double Helix** with oscillating laser beam, Level 1 Emergency hotline, centers of excellence, and triage appointment booking.

### Quick Start
```bash
npm install
npm run dev
```
Visit `http://localhost:3002`
